# ✅ Todo App

## 📌 Présentation

Todo App est une application web simple permettant de gérer efficacement ses tâches quotidiennes. Elle offre aux utilisateurs la possibilité d'ajouter, modifier, marquer comme terminées et supprimer des tâches afin d'améliorer leur organisation personnelle et leur productivité.

Ce projet a été développé dans le but de mettre en pratique les concepts fondamentaux du développement web tels que la gestion de l'état, les opérations CRUD et la conception d'interfaces utilisateur intuitives.

---

## 🎯 Objectifs

- Organiser les tâches quotidiennes.
- Simplifier le suivi des activités.
- Améliorer la gestion du temps.
- Découvrir les opérations CRUD (Create, Read, Update, Delete).
- Développer une application web responsive et conviviale.

---

## ✨ Fonctionnalités

### 📝 Gestion des tâches

- Ajouter une nouvelle tâche
- Modifier une tâche existante
- Supprimer une tâche
- Marquer une tâche comme terminée
- Afficher la liste des tâches

### 🔍 Suivi des tâches

- Visualiser les tâches en cours
- Identifier rapidement les tâches terminées
- Mettre à jour l'état d'une tâche

### 🎨 Interface utilisateur

- Interface simple et intuitive
- Design responsive
- Expérience utilisateur fluide

## ⚙️ Installation

### Cloner le dépôt

```bash
git clone https://github.com/Malaak50/todo.git
cd todo
```

### Installer les dépendances

```bash
npm install
```

### Lancer l'application

```bash
npm start
```

L'application sera accessible à l'adresse :

```text
http://localhost:3000
```
